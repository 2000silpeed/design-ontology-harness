# TacticLens — 축구 영상 전술 분석 앱 초기 기획서

## 제품 개요
TacticLens는 축구 경기 영상을 업로드하면 사용자가 선택한 팀의 **전술 의도**, **실제 이행 여부**, **실패/성공 장면 근거**를 자동으로 정리해 주는 코칭/분석 워크스페이스다.  
핵심은 "AI가 결론만 말하는 리포트"가 아니라, 코치와 분석가가 영상 타임라인 위에서 근거를 검토하고 수정할 수 있는 **증거 기반 전술 리뷰 도구**다.

## 제품 약속
경기 전체를 다시 돌려보지 않아도, 팀이 약속한 전술 원칙을 어느 구간에서 지켰고 어디서 무너졌는지 클립·피치맵·체크리스트로 빠르게 확인한다.

## 핵심 사용자
- **프로/세미프로 분석관**: 경기 후 2~4시간 안에 코칭스태프용 분석 리포트와 클립을 만들어야 한다.
- **유소년/아마추어 코치**: 전술 원칙은 있지만 전문 분석팀이 없어 영상 리뷰 시간을 줄이고 싶다.
- **전술 콘텐츠 크리에이터**: 특정 팀의 빌드업, 압박, 전환 구조를 시각 자료와 함께 설명하고 싶다.
- **선수/팀 퍼포먼스 담당자**: 반복적으로 깨지는 약속, 라인 간격, 압박 타이밍을 데이터로 추적하고 싶다.

## 문제 정의
- 영상은 있지만 전술 리뷰는 여전히 사람이 긴 시간을 들여 수동으로 본다.
- "좋았다/나빴다"는 코멘트는 남지만, 어느 장면에서 어떤 원칙이 지켜졌는지 근거가 흩어진다.
- 선수 추적, 이벤트 태깅, 팀 형태 분석, 리포트 작성 도구가 분리되어 있어 작은 팀은 도입하기 어렵다.
- 자동 분석 결과가 틀릴 때 수정하거나 학습시킬 인터페이스가 부족하다.

## MVP 가정
- 사용자는 업로드 시 분석 대상 팀을 직접 선택한다. 홈/원정 또는 유니폼 색상으로 지정한다.
- 첫 버전은 11v11 경기 영상, 하프코트가 자주 보이는 중계/광각 영상, 720p 이상을 우선 지원한다.
- 완전 자동 판정 대신 "AI 초안 + 사용자 검수" 흐름을 기본 UX로 둔다.
- 개인 선수 식별은 선택 기능이다. MVP는 선수 번호/이름보다 팀 단위 구조와 라인, 간격, 전술 원칙 이행을 먼저 본다.
- 전술 의도는 앱이 추론한 초안과 사용자가 미리 정의한 팀 플레이북을 함께 사용한다.

## 비범위
- 심판 판정, 부상 위험 예측, 베팅 확률 예측은 다루지 않는다.
- 고정 카메라가 전혀 없고 장면 전환이 극단적으로 많은 하이라이트 영상만으로 전체 전술을 단정하지 않는다.
- 영상 권리 관리/배포 플랫폼이 아니라, 팀 내부 분석과 리포트 생성을 우선한다.

## 핵심 플로우
1. **새 분석 생성**
   - 경기명, 날짜, 상대, 분석 대상 팀, 영상 소스, 전술 목표를 입력한다.
   - 업로드 가능 형식: mp4, mov, m4v.
   - 사용자는 홈/원정, 유니폼 색상, 전반/후반 분리 여부를 지정한다.

2. **영상 처리 대기열**
   - 업로드, 트랜스코딩, 프레임 샘플링, 피치 보정, 선수/공 추적, 이벤트 탐지, 전술 추론 상태를 단계별로 보여준다.
   - 실패 시 어느 단계에서 멈췄는지와 재시도 옵션을 제공한다.

3. **AI 분석 초안 확인**
   - 포메이션 추정, 공격/수비 형태, 압박 높이, 빌드업 패턴, 전환 후 구조를 요약한다.
   - 확신도가 낮은 구간은 "검수 필요"로 표시한다.

4. **전술 원칙 설정**
   - 사용자는 팀의 의도된 전술을 체크리스트로 정의한다.
   - 예: 후방 빌드업 3-2 구조, 풀백 안쪽 진입, 1차 압박 유도 방향, 역압박 5초 룰, 수비 시 4-4-2 블록.

5. **이행 여부 분석**
   - 앱은 각 원칙별로 성공/부분 성공/실패 장면을 타임라인에 묶는다.
   - 각 판단에는 클립, 피치맵, 관련 선수 위치, 텍스트 근거가 따라붙는다.

6. **리뷰와 수정**
   - 분석가는 AI가 잘못 태깅한 구간을 수정하고, 원칙 판정을 바꿀 수 있다.
   - 수정 내역은 팀 플레이북과 다음 분석의 힌트로 남긴다.

7. **리포트 생성**
   - 코칭스태프용 요약, 선수 미팅용 클립 묶음, 세부 분석 PDF/링크를 생성한다.
   - 리포트는 "결론 → 근거 장면 → 개선 포인트" 순서로 구성한다.

## 주요 화면
1. **Project Library**
   - 최근 경기 분석, 처리 상태, 상대 팀, 최종 이행 점수, 검수 필요 개수를 보여주는 리스트.
   - 빠른 필터: 팀, 시즌, 대회, 분석 상태, 검수 필요.

2. **New Analysis / Upload**
   - 파일 선택 또는 놓기 방식의 업로드.
   - 대상 팀 선택, 유니폼 색상 swatch, 경기 메타데이터, 전술 템플릿 선택.
   - 업로드 전 예상 처리 시간과 영상 품질 체크.

3. **Processing Queue**
   - 단계형 프로그레스: Ingest → Transcode → Field Calibration → Tracking → Event Detection → Tactical Inference → Report Build.
   - 단계별 로그, 재시도, 실패 원인 표시.

4. **Analysis Workspace**
   - 좌측: 비디오 플레이어와 오버레이 컨트롤.
   - 중앙 하단: 전술 이벤트 타임라인.
   - 우측: 현재 구간의 원칙 판정, 근거, 수정 패널.
   - 보조 뷰: 피치맵, 팀 쉐이프, 라인 높이, 폭/간격, 압박 트리거.

5. **Tactical Playbook**
   - 팀이 의도한 전술 원칙을 저장하는 화면.
   - 국면별 원칙: 빌드업, 전진, 파이널서드, 수비 블록, 압박, 역압박, 공수 전환, 세트피스.
   - 각 원칙에는 체크 조건과 실패 조건을 정의한다.

6. **Execution Report**
   - 원칙별 이행률, 대표 성공/실패 클립, 전반/후반 변화, 상대 대응 변화.
   - 코치 코멘트와 액션 아이템을 붙인다.

7. **Clip Shelf**
   - 자동 생성된 클립을 묶어 선수 미팅용 순서로 편집한다.
   - 클립별 제목, 코멘트, 태그, 공개 범위를 설정한다.

8. **Review Queue**
   - AI 확신도가 낮거나 충돌하는 판정을 모아 보여준다.
   - 분석가가 빠르게 승인/수정/제외할 수 있다.

9. **Team Settings**
   - 팀, 선수 명단, 유니폼 색상, 기본 포메이션, 시즌, 사용자 권한 관리.

## 도메인 모델
- **VideoAsset**: 원본 영상, 해상도, 길이, FPS, 업로드 상태.
- **Match**: 경기명, 날짜, 상대, 홈/원정, 분석 대상 팀, 전후반 구간.
- **TeamProfile**: 팀 색상, 플레이북, 기본 포메이션, 선수 명단.
- **PlayerTrack**: 선수 위치, 속도, 팀 분류, 추적 확신도.
- **BallTrack**: 공 위치, 소유 추정, 추적 확신도.
- **Event**: 패스, 슈팅, 압박, 탈압박, 라인 브레이크, 볼 회복, 전환, 세트피스.
- **PhaseSegment**: 빌드업, 전진, 파이널서드, 수비 조직, 압박, 역압박, 공격 전환, 수비 전환.
- **TacticalPrinciple**: 사용자가 정의한 전술 원칙과 체크 조건.
- **ExecutionCheck**: 특정 원칙이 특정 구간에서 성공/부분 성공/실패했는지에 대한 판정.
- **Clip**: 리포트에 들어갈 시작/끝 시간, 썸네일, 오버레이, 코멘트.
- **Report**: 요약, 수치, 근거 클립, 개선 포인트.

## 분석 파이프라인
1. **Ingest**
   - 영상 업로드, 무결성 체크, 길이/해상도/FPS 추출.
   - 전후반이 나뉘지 않은 영상은 사용자가 구간을 자를 수 있게 한다.

2. **Transcode**
   - 분석용 저용량 프록시와 원본 보존본을 분리한다.
   - 웹 플레이어용 스트리밍 포맷을 생성한다.

3. **Frame Sampling**
   - 전체 영상에서 일정 간격 프레임과 이벤트 후보 프레임을 추출한다.
   - 전술 변화가 큰 구간은 더 촘촘하게 샘플링한다.

4. **Field Calibration**
   - 피치 라인, 페널티 박스, 센터서클 등 기준선을 찾아 2D 피치 좌표로 보정한다.
   - 보정 실패 구간은 검수 대상이 된다.

5. **Player / Ball Detection**
   - 선수, 골키퍼, 심판, 공을 탐지한다.
   - 팀 색상과 위치 연속성을 사용해 대상 팀/상대 팀을 분류한다.

6. **Tracking**
   - 프레임 간 선수와 공의 ID를 연결한다.
   - 가려짐이나 카메라 컷으로 끊긴 구간은 확신도와 함께 표시한다.

7. **Event Detection**
   - 패스, 운반, 압박, 볼 회복, 슈팅, 롱볼, 세트피스, 라인 브레이크 후보를 감지한다.
   - 이벤트는 자동 태그와 사람이 고친 태그를 모두 가진다.

8. **Phase Segmentation**
   - 볼 소유, 위치, 팀 형태, 압박 강도에 따라 국면을 나눈다.
   - 한 클립이 여러 국면에 걸치면 시작/종료 지점을 조정할 수 있다.

9. **Tactical Inference**
   - 포메이션, 라인 높이, 수비 블록 폭, 선수 간격, 풀백/미드필더 위치 관계를 계산한다.
   - 반복 패턴을 찾아 빌드업 구조, 압박 방향, 전환 행동을 요약한다.

10. **Execution Scoring**
    - 플레이북 원칙별 체크 조건과 실제 장면을 비교한다.
    - 점수는 단일 숫자보다 근거 장면과 함께 보여준다.

11. **Human Review**
    - 분석가가 판정, 이벤트, 클립 구간, 코멘트를 수정한다.
    - 수정 기록은 같은 팀의 다음 경기 분석 힌트가 된다.

12. **Report Generation**
    - 코칭스태프용 요약, 선수 미팅용 클립 묶음, 데이터 테이블을 생성한다.
    - 모든 결론은 원본 영상 시간대와 연결된다.

## 전술 분석 항목
- **빌드업 구조**: 2-3, 3-2, 3-1, 비대칭 풀백, 골키퍼 관여.
- **전진 방식**: 중앙 침투, 측면 overload, 하프스페이스 활용, 롱볼 타깃.
- **공격 폭/깊이**: 윙어 폭 유지, 풀백 overlap/underlap, 최전방 라인 고정.
- **수비 블록**: 4-4-2, 4-1-4-1, 5-4-1, 미드블록/로우블록.
- **압박**: 1차 압박 타이밍, 유도 방향, 센터백/골키퍼 압박, 커버 섀도우.
- **역압박**: 볼 상실 후 5초 내 압박, 주변 선수 거리, 후방 rest defense.
- **공수 전환**: 볼 회복 후 첫 패스 방향, 전진 속도, 수비 전환 지연.
- **라인 관리**: 수비 라인 높이, 미드필드-수비 간격, 좌우 compactness.
- **세트피스**: 코너킥 배치, 프리킥 수비, 세컨볼 대응.

## 핵심 수치
- 전술 원칙별 이행률.
- 검수 완료율과 AI 판정 수정률.
- 국면별 점유 시간과 위험 구간.
- 압박 성공률, 볼 회복 위치, 탈압박 허용 횟수.
- 수비 블록 평균 높이와 폭.
- 라인 간격 평균/최대 이탈.
- 역압박 반응 시간.
- 빌드업 패턴 반복 빈도.
- 전반/후반 전술 이행 변화.

## UI 컴포넌트
- **app-shell**: 좌측 네비게이션, 상단 경기 컨텍스트, 작업 영역.
- **project-table**: 경기 분석 리스트, 상태, 점수, 검수 필요 개수.
- **upload-dropzone**: 영상 파일 업로드, 파일 품질 체크, 업로드 진행률.
- **team-selector**: 홈/원정, 유니폼 색상, 대상 팀 선택.
- **kit-color-swatch**: 유니폼 색상 선택과 팀 분류 힌트.
- **video-player**: 프록시 영상 재생, 속도 조절, 프레임 이동.
- **overlay-toggle-bar**: 선수 트랙, 공 트랙, 팀 쉐이프, 압박 구역, 피치 라인 토글.
- **analysis-timeline**: 국면, 이벤트, 원칙 판정, 검수 상태가 겹쳐진 멀티 레이어 타임라인.
- **phase-chip**: 빌드업/압박/전환 등 국면 표시.
- **principle-check-card**: 원칙별 성공/부분 성공/실패 판정 카드.
- **confidence-badge**: AI 확신도와 검수 필요 상태.
- **pitch-map**: 2D 피치 좌표, 선수 위치, 라인, 점유 구역.
- **shape-panel**: 팀 형태, 라인 높이, 폭, compactness.
- **event-card**: 이벤트명, 시간, 관련 선수, 근거, 수정 액션.
- **review-queue-list**: 검수 필요한 판정 큐.
- **clip-card**: 썸네일, 시작/끝 시간, 태그, 코멘트.
- **report-section**: 요약, 수치, 클립 묶음, 액션 아이템.
- **playbook-editor**: 전술 원칙 작성, 체크 조건, 국면 연결.
- **condition-builder**: 라인 높이, 선수 거리, 압박 시간 같은 조건 설정.
- **processing-stepper**: 분석 파이프라인 단계와 로그.
- **metric-tile**: 이행률, 압박 성공률, 라인 간격 등 핵심 숫자.
- **comparison-chart**: 전반/후반, 경기별, 원칙별 비교.
- **annotation-toolbar**: 이벤트 추가, 구간 자르기, 판정 수정, 코멘트 입력.
- **export-dialog**: PDF, 링크, 클립 묶음 내보내기.

## 인터랙션 원칙
- 영상 조작은 단축키 중심으로 설계한다: Space 재생/정지, J/K/L 탐색, ←/→ 프레임 이동.
- 분석가는 타임라인에서 바로 판정을 승인/수정할 수 있어야 한다.
- AI 결과는 항상 확신도와 근거를 같이 보여준다.
- 틀린 자동 분석을 숨기지 않고, "검수 필요" 큐로 모아 작업 흐름에 포함한다.
- 피치맵과 영상은 같은 시간대를 공유한다. 타임라인 클릭 시 둘 다 즉시 이동한다.
- 원칙 점수는 점수판처럼 크게 보이되, 클릭하면 근거 클립으로 내려간다.
- 코칭 미팅용 내보내기는 복잡한 설정 없이 2~3단계로 끝나야 한다.

## 데이터 검증 정책
- 모든 자동 판정은 confidence score를 가진다.
- 낮은 confidence 구간은 리포트의 확정 결론에 바로 포함하지 않는다.
- 사용자가 수정한 판정은 "human reviewed"로 표시한다.
- 분석 모델 버전과 처리 시간을 리포트 메타데이터에 남긴다.

## 접근성
- WCAG 2.2 AA를 목표로 한다.
- 영상 플레이어 컨트롤은 단축키와 스크린 리더 라벨을 제공한다.
- 피치맵 색상은 색각 이상 사용자를 위해 패턴/선/아이콘 차이를 함께 사용한다.
- 타임라인의 이벤트는 색상만으로 구분하지 않고 텍스트 라벨과 아이콘을 병행한다.
- 움직임이 많은 오버레이는 prefers-reduced-motion 설정을 따른다.

## 한글 UX
- 한국어를 1급 언어로 둔다.
- 축구 현장에서 쓰는 표현을 우선한다: 빌드업, 역압박, 라인 간격, 압박 유도, 하프스페이스, 세컨볼, 전환.
- 리포트 문장은 짧고 코칭 회의에서 바로 읽을 수 있어야 한다.
- 영어 용어는 필요한 경우 괄호로 병기한다: compactness, rest defense, trigger.

## 성공 기준
- 사용자가 90분 경기 업로드 후 15분 안에 AI 분석 초안을 확인할 수 있다.
- 분석가는 30분 안에 검수된 코칭스태프용 요약 리포트를 만들 수 있다.
- 모든 핵심 결론은 원본 영상 시간대와 연결된다.
- 원칙별 이행/미이행 판단을 사용자가 수정할 수 있다.
- 같은 팀의 플레이북을 재사용해 경기별 변화를 비교할 수 있다.

## 첫 번째 프로토타입 우선순위
1. 업로드 화면과 처리 대기열.
2. 비디오 플레이어 + 분석 타임라인 + 피치맵이 있는 워크스페이스.
3. 전술 원칙 플레이북 작성.

5. 리포트 요약과 클립 카드 내보내기 목업.
