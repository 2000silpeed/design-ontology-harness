# TacticLens YouTube Design System

축구 전술 분석 유튜브 영상을 만들기 위한 영상용 디자인 시스템이다.

앱 UI 시스템이 화면과 컴포넌트를 정의한다면, 이 폴더는 유튜브 제작에 필요한
썸네일, 타이틀 카드, 자막, lower third, 피치맵 오버레이, 챕터 카드, Shorts 변형,
편집 리듬을 정의한다.

## Files

- `VIDEO_DESIGN_SYSTEM.md`: 채널 비주얼/편집 시스템 본문
- `PRODUCTION_TEMPLATES.md`: 롱폼/Shorts/클립별 제작 템플릿
- `PRODUCTION_CHECKLIST.md`: 업로드 전 검수 체크리스트
- `tokens/video_tokens.json`: 색상, 서체, 크기, 모션 토큰
- `templates/script_outline.md`: 전술 분석 영상 대본 구조
- `preview/index.html`: 썸네일/영상 컴포넌트 HTML 프리뷰
- `preview/styles.css`: 프리뷰 스타일

## Preview

`preview/index.html`을 브라우저에서 열면 된다.

## Base Direction

- 채널 유형: 축구 전술 분석 / 코칭 인사이트 / 경기 리뷰
- 톤: precise, coach-like, evidence-first
- 시각 언어: pitch green, cyan tracking overlay, amber coaching highlight, chalk linework
- 핵심 약속: 모든 주장에는 영상 시간대, 피치맵, 장면 근거가 붙는다.
