# Production Checklist

## Before Editing

- [ ] 오늘의 질문이 한 문장으로 정리되어 있다.
- [ ] 분석 대상 팀과 전술 원칙이 명확하다.
- [ ] 사용할 경기 장면의 시간대가 기록되어 있다.
- [ ] 성공 장면과 실패 장면이 최소 1개씩 있다.

## Visual

- [ ] 썸네일 제목은 2줄 이하이다.
- [ ] 전술 라인 색상은 green/cyan/amber/crimson 규칙을 따른다.
- [ ] 피치맵과 영상 오버레이가 원본 장면을 과하게 가리지 않는다.
- [ ] lower third는 5초 이상 머물지 않는다.
- [ ] 챕터 카드가 매번 같은 위치/크기/모션을 사용한다.

## Caption

- [ ] 자막은 최대 2줄이다.
- [ ] 한글 줄바꿈이 어색하지 않다.
- [ ] 전문 용어는 첫 등장 때만 괄호 병기한다.
- [ ] 모바일에서 자막이 YouTube UI에 가리지 않는다.

## Evidence

- [ ] 모든 핵심 주장은 장면 시간대와 연결된다.
- [ ] "좋다/나쁘다" 대신 어떤 원칙이 지켜졌는지 말한다.
- [ ] AI 추정 또는 확신도가 낮은 내용은 단정하지 않는다.

## Export

- [ ] Long-form: 1920x1080
- [ ] Shorts: 1080x1920
- [ ] Thumbnail: 1280x720
- [ ] 오디오 피크가 깨지지 않는다.
- [ ] 업로드 제목/설명/챕터 타임코드가 준비되어 있다.
