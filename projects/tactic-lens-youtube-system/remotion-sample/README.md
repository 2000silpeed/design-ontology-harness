# TacticLens Remotion Sample

60-second Remotion sample for the TacticLens YouTube design system.

Composition:

- `TacticLensMinute`
- `1280x720`
- `30fps`
- `1800 frames`

## Commands

```bash
npm install
npm run preview
npm run render:still
npm run render
```

Output:

- `out/tacticlens-minute.mp4`
- `out/thumbnail.png`
- `out/frame-30s.png`
