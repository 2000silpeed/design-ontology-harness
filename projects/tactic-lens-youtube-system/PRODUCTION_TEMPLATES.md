# Production Templates

## Long-form Analysis

권장 길이: 8~12분

| Time | Block | Visual |
|------|-------|--------|
| 0:00-0:08 | Hook | 경기 장면 + 오늘의 질문 |
| 0:08-0:20 | Context | 매치 카드, 포메이션, 대상 팀 |
| 0:20-1:10 | Principle | 전술 원칙 카드 + 피치맵 |
| 1:10-3:00 | Evidence 1 | 영상 + tracking overlay |
| 3:00-4:40 | Pattern | 피치맵 breakdown |
| 4:40-6:20 | Evidence 2 | 성공/실패 split screen |
| 6:20-8:30 | Adjustment | 전반/후반 변화 |
| 8:30-9:30 | Coaching takeaway | principle check card |
| 9:30-end | Summary | 3-line summary + next video |

## Quick Breakdown

권장 길이: 4~6분

1. 질문
2. 한 장면
3. 피치맵 설명
4. 반대 장면
5. 결론

## Shorts

권장 길이: 35~55초

| Time | Block |
|------|-------|
| 0:00-0:03 | 강한 질문 |
| 0:03-0:12 | 문제 장면 |
| 0:12-0:25 | 피치맵 해설 |
| 0:25-0:42 | 성공/실패 비교 |
| 0:42-0:55 | 한 줄 결론 |

## Thumbnail Template A: Tactical Question

- Background: dark pitch map
- Title: left 60%, 2 lines
- Tactical marks: right 40%
- Series label: top-left
- Time or formation badge: bottom-right

## Thumbnail Template B: Failure Moment

- Background: match frame crop
- Problem marker: crimson ring + amber arrow
- Title: bottom-left
- Context badge: top-right

## Thumbnail Template C: Pattern Breakdown

- Background: simplified pitch
- Shape: central tactical diagram
- Title: top-left
- Result badge: lower-right
