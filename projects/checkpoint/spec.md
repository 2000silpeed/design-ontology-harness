# Checkpoint 상세 설계서

## 1. 제품 개요

Checkpoint는 콘솔과 PC 게임을 비평, 비교, 추천하는 에디토리얼 게임 리뷰 사이트다. 사용자는 신작 리뷰를 빠르게 훑고, 플랫폼별 성능과 장단점을 비교하고, 지금 구매할지 나중에 담아둘지 판단할 수 있어야 한다.

## 2. 주요 화면

### 2.1 홈 피드 / 메인 랜딩

사용자가 접속하면 가장 먼저 이번 주의 핵심 리뷰와 추천 큐레이션이 보인다.

- 히어로 영역에 대표 리뷰 게임의 커버 아트, 한 줄 verdict, 종합 점수
- 최신 리뷰 카드 그리드에 플랫폼 태그, 장르, 메타 정보, 점수 배지 표시
- 에디터 추천 섹션에 “지금 할 게임”, “기다릴 게임”, “패치 후 재평가” 큐레이션
- 최근 업데이트 영역에 리뷰 수정, 패치 반영, 성능 테스트 갱신 내역 표시

### 2.2 리뷰 상세 페이지

개별 게임의 리뷰 본문과 평가 근거를 보여준다.

- 대형 커버 이미지 또는 스크린샷 갤러리
- 총평, 장점/단점, 추천 대상, 플랫폼별 퍼포먼스 요약
- 점수 브레이크다운: 전투, 서사, 최적화, 접근성, 반복 플레이 가치
- 스포일러 토글 섹션과 패치 이후 업데이트 로그
- 관련 게임 또는 대체 추천 카드

### 2.3 랭킹 / 차트

사용자가 높은 평점을 받은 게임을 빠르게 탐색한다.

- 올해 최고 평점 게임 리스트
- 장르별 필터와 플랫폼별 필터
- 최근 30일 상승작, 기대작, 재평가작 뱃지
- 정렬 옵션: 점수, 출시일, 플레이타임, 접근성 평가

### 2.4 비교 / 구매 판단 도구

비슷한 장르나 시리즈의 게임을 한 화면에서 비교한다.

- 비교 테이블에 가격, 리뷰 점수, 플레이타임, 한국어 지원, 성능 모드 여부 표시
- “지금 사도 됨”, “세일 대기”, “패치 대기” 상태 라벨
- 에디터 코멘트가 붙은 비교 하이라이트 카드

### 2.5 검색 / 발견

게임명, 스튜디오, 장르로 원하는 항목을 찾는다.

- 글로벌 검색바와 자동완성 드롭다운
- 장르, 플랫폼, 평점 범위, 출시 시기 필터
- 최근 검색 기록과 인기 검색어

## 3. 공통 요소

- 리뷰 점수 뱃지: Must Play, Strong Buy, Wait for Patch, Skip
- 플랫폼 태그: PS5, Xbox, Switch, PC, Steam Deck
- 데이터 카드와 비교 표가 함께 쓰이는 반응형 레이아웃
- 모바일에서는 카드 우선, 데스크톱에서는 카드 + 표 혼합 레이아웃
- 접근성: 색만으로 상태를 구분하지 않고 텍스트와 아이콘을 함께 사용
