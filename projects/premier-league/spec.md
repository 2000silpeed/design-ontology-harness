# PL Stats 상세 설계서

## 1. 제품 개요

프리미어리그 경기 결과, 리그 순위표, 선수별 상세 통계를 실시간으로 제공하는 스포츠 데이터 웹사이트.

## 2. 주요 화면

### 2.1 메인 대시보드

사용자가 접속하면 오늘의 경기와 주요 통계가 표시됩니다.
- 상단 네비게이션 바에 리그, 일정, 순위, 선수 메뉴
- 히어로 영역에 오늘의 라이브 스코어 카드
- 통계 카드: 득점왕, 어시스트왕, 클린시트 순위
- 최근 경기 결과 목록

### 2.2 리그 순위표

프리미어리그 전체 순위를 테이블로 표시합니다.
- 순위, 팀명, 경기수, 승/무/패, 득점, 실점, 골득실, 승점
- 컬럼별 정렬 가능
- 챔피언스리그/강등권 영역 시각적 구분 (태그, 배경색)
- 최근 5경기 폼 표시 (승/무/패 뱃지)
- 시즌 필터 드롭다운

### 2.3 경기 상세

개별 경기의 상세 정보를 표시합니다.
- 두 팀 스코어와 골 타임라인
- 선수 명단과 교체 정보
- 경기 통계 비교 차트 (점유율, 슈팅, 패스 등)
- 주요 이벤트 타임라인 (골, 카드, 교체)

### 2.4 선수 프로필

개별 선수의 상세 통계 페이지입니다.
- 선수 기본 정보 (이름, 포지션, 국적, 등번호)
- 시즌 통계 카드 (골, 어시스트, 출전, 평점)
- 경기별 통계 테이블
- 능력치 레이더 차트
- 시즌 성적 추이 라인 차트

### 2.5 검색

글로벌 검색으로 팀과 선수를 찾습니다.
- 검색바에 팀명 또는 선수명 입력
- 자동완성 드롭다운
- 검색 결과에 팀/선수 구분 태그
- 최근 검색 기록

## 3. 공통 요소

- 실시간 스코어 업데이트 표시 (라이브 뱃지)
- 경기 상태 뱃지: LIVE, FT, HT, 예정
- 팀 로고와 유니폼 색상 활용
- 반응형 레이아웃 (데스크톱/모바일)
