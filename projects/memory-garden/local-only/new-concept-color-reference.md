# Memory Garden — New Concept Color Notes

This palette is authored for the Memory Garden concept and is not imported from another project or reference pack.

## Memory Garden authored palette

### Deep Dusk
- **Hex**: #102A2B
- **Tone/Mood**: temporal anchor, grounded, quiet depth
- **Usage**: primary ink and deep semantic anchor
- **Mood Tags**: [temporal, grounded, quiet]

### Mineral Violet
- **Hex**: #5C4B73
- **Tone/Mood**: reflection, decision, considered emphasis
- **Usage**: decision and return emphasis
- **Mood Tags**: [reflective, considered, editorial]

### Lichen Green
- **Hex**: #8BA889
- **Tone/Mood**: care, continuation, living accent
- **Usage**: care state and return affordance
- **Mood Tags**: [care, living, calm]

### Warm Paper
- **Hex**: #E8DFC9
- **Tone/Mood**: reading surface, memory, tactile quiet
- **Usage**: primary reading surface
- **Mood Tags**: [paper, tactile, quiet]

The colors are semantic candidates only. Components must consume generated
`--ds-*` tokens rather than these hex values directly.
