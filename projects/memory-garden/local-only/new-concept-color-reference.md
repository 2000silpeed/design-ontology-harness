# Memory Garden — New Concept Color Notes

This palette is authored for the Memory Garden concept and is not imported from
another project or reference pack.

- Deep Dusk `#102A2B`: temporal anchor and primary text/surface contrast.
- Mineral Violet `#5C4B73`: decision and reflection emphasis.
- Lichen Green `#8BA889`: care-state accent and return affordance.
- Warm Paper `#E8DFC9`: quiet reading surface.

The colors are semantic candidates only. Components must consume generated
`--ds-*` tokens rather than these hex values directly.
