# Meadow

This folder is a self-contained harness project built on top of `design-ontology-harness`.

타깃: **Consumer wellness / habit admin dashboard (dashboard--playful-soft)** — Cal.com/Flo/Finch/Calm/Headspace
스타일의 habit streak · wellness score · mood check · mindful insight 를 playful-soft 톤으로 한 화면에 모은
consumer wellness admin 콘솔.

## Files

- `brand_profile.json`: Periwinkle + Peach Puff + Mauve 팔레트, Nunito / Inter / Pretendard
- `seeds/seed_urls.txt`: Cal.com / Notion / Flo / Finch / Calm / Headspace
- `project_manifest.json`: project metadata
- `agent_brief.md`: instructions for human or agent collaborators
- `build/`: generated outputs

## How To Run

```bash
uv run design-ontology run-project --project-dir projects/meadow
```
