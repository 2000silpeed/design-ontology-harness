# ColorFit 모바일 웹 UI 설계서

> 모바일 퍼스트 패션 추천 앱. 모든 화면은 390px 기준, 최대 768px.
> 하단 탭 네비게이션 기반 싱글 페이지 앱 구조.

## 글로벌 네비게이션

### 하단 탭바 (BottomTabBar)
- 5개 탭: 피드, 비교, 저장, 옷장, 프로필
- 고정 하단, safe-area 대응 (iOS notch/home indicator)
- 활성 탭: Marsala 아이콘 + 라벨, 비활성: muted gray
- 탭 전환 시 fade 트랜지션 (150ms)
- 높이: 56px + safe-area-inset-bottom

### 상단 헤더 (TopBar)
- 좌측: 뒤로가기 (chevron) 또는 로고
- 중앙: 페이지 타이틀 (Nanum Myeongjo, 18px)
- 우측: 액션 아이콘 (필터, 알림 등)
- 높이: 48px, 배경 blur (backdrop-filter)
- 스크롤 시 그림자 나타남 (elevation)

## 온보딩 (5단계 풀스크린)

### Step 1: 성별 선택
- 풀스크린, 2개 큰 카드 (남성/여성)
- 카드: 160px 높이, 라운드 12px, 탭으로 선택
- 선택 시 Marsala 보더 + 체크 아이콘
- 하단: "다음" CTA 버튼 (풀 너비)

### Step 2: 퍼스널컬러 12톤 선택
- 계절별 그룹핑 (봄/여름/가을/겨울)
- 각 톤: 원형 컬러 스와치 (48px) + 라벨
- 선택된 톤: scale 1.15 + ring + 이름 강조
- 상단: 진행 바 (step 2/5)
- 하단: "나의 톤을 잘 모르겠어요" 링크

### Step 3: TPO 선택 (복수 선택)
- 8개 TPO 칩 (성별에 따라 다른 세트)
- 칩: pill shape, 탭으로 토글
- 선택됨: Marsala 배경 + 흰 텍스트
- 미선택: 보더만, 투명 배경
- 최소 1개 선택 필수

### Step 4: 예산 설정
- 상의/하의/아우터 3개 카테고리별 범위 슬라이더
- 슬라이더: 듀얼 thumb, Marsala 트랙
- 각 카테고리 라벨 + 현재 범위 표시 (만원 단위)
- 프리셋 버튼: "가성비", "중간", "프리미엄"

### Step 5: 비주얼 취향 분석 (Style Seed)
- 4라운드 이미지 선택
- 각 라운드: 4장 이미지 그리드 (2x2)
- 이미지: 정사각형, 라운드 8px, 탭으로 선택
- 선택 시 Marsala 오버레이 + 체크
- 라운드 간 슬라이드 트랜지션

## 코디 피드 (메인 화면)

### 피드 헤더
- "오늘의 코디" 타이틀 (Nanum Myeongjo, 24px)
- 1줄 서브 텍스트: "{톤이름}님을 위한 추천"
- TPO 필터 탭: 수평 스크롤 칩 리스트
- 활성 필터: Marsala underline

### 코디 카드 (OutfitCard) - 핵심 컴포넌트
- 풀 너비 카드, 세로 스크롤 피드
- 상단: 코디 이미지 (aspect-ratio 3:4, 라운드 12px 상단)
- 이미지 위 오버레이:
  - 좌상단: Top Pick 뱃지 (조건부)
  - 우상단: 하트(저장) 아이콘 버튼
- 이미지 아래 정보 영역 (패딩 16px):
  - 코디 이름 (Pretendard, 16px, semibold)
  - 1줄 요약 (13px, muted)
  - 스코어 뱃지 2개: PCF %, OF % (pill, 작은 크기)
  - 총 가격 (16px, bold) + 아이템 수
- 카드 간 간격: 24px
- 카드 등장 애니메이션: fadeInUp, stagger 0.1s

### 빈 상태
- 일러스트 아이콘 (옷걸이)
- "아직 추천할 코디가 없어요" 메시지
- "취향 설정 변경하기" 버튼

## 코디 상세 (바텀시트 또는 풀스크린)

### 코디 상세 시트
- 바텀시트: 화면 85% 높이, 드래그로 닫기
- 상단: 드래그 핸들 (40px x 4px, 라운드)
- 코디 대표 이미지 (풀 너비)
- 코디 이름 + 추천 이유 2줄
- 스코어 바 차트:
  - 5축 (PCF/OF/CH/PE/SF)
  - 각 축: 라벨 + 가로 바 + 점수
  - 바 색상: 각 축별 고유 색상
  - 바 등장 애니메이션: width 0→실제값, stagger 0.15s
- 아이템 리스트:
  - 각 아이템: 썸네일(64px) + 이름 + 카테고리 + 가격
  - 탭 시 아이템 상세로 이동

## 아이템 상세

### 아이템 상세 페이지
- 상품 이미지 (풀 너비, swipeable 갤러리)
- 상품명 + 브랜드
- 가격 (큰 글씨, 24px, bold)
- 퍼스널컬러 적합도 표시 (원형 progress + 점수)
- 색상 스와치 (available colors)
- "비슷한 상품" 수평 스크롤 리스트
- 하단 고정 CTA: "최저가로 보기" 버튼 (풀 너비, Marsala)

### 가격 비교 테이블
- 판매처별 행: 로고 + 가격 + "바로가기" 버튼
- 최저가 행 강조 (배경색 + "최저가" 뱃지)
- 외부 링크 아이콘 표시

## A vs B 비교

### 비교 화면
- 2-column 레이아웃 (각 50% 너비)
- 상단: 두 코디 이미지 나란히
- 중단: 5축 스코어 비교 (나란히 바 차트)
- 하단: "이 코디가 더 좋아요" 버튼 2개
- 승자 결과: confetti 마이크로 애니메이션 (선택적)

## 저장 목록

### 저장 피드
- 그리드 레이아웃 (2열)
- 각 셀: 코디 이미지 + 이름 + 가격
- 우상단: 저장 해제 하트
- 스와이프 왼쪽: 삭제 확인
- 빈 상태: "아직 저장한 코디가 없어요"

## 옷장 (Closet)

### 옷장 그리드
- 내 옷 사진 그리드 (3열)
- 우하단: "+" 업로드 FAB 버튼
- 각 아이템 탭 → 분석 결과

### 옷 분석 결과
- 업로드 사진 (풀 너비)
- 퍼스널컬러 점수 + 이유
- "이 옷에 어울리는 코디" 추천 카드 리스트
- "AI 착장 보기" CTA

### 사진 업로드
- 카메라 / 갤러리 선택 바텀시트
- 업로드 진행 표시 (circular progress)
- 분석 중 스켈레톤 로딩

## AI 가상 피팅

### 피팅 결과 화면
- AI 생성 이미지 (풀 너비, 라운드 12px)
- "다시 생성" 버튼
- 원본 아이템 목록 (수평 스크롤 썸네일)
- 생성 중: 로딩 애니메이션 (pulse + skeleton)

## 프로필 / 마이페이지

### 프로필 화면
- 상단: 프로필 카드 (톤 이름 + 색상 원)
- 메뉴 리스트:
  - 퍼스널컬러 재설정
  - TPO/예산 변경
  - 취향 초기화
  - 프리미엄 구독
  - 로그아웃
- 각 메뉴: 아이콘 + 라벨 + chevron

## 모바일 특화 패턴

### 터치 인터랙션
- 모든 터치 타겟: 최소 44px x 44px (WCAG)
- 탭 피드백: 100ms scale(0.97) + opacity(0.7)
- 스와이프 제스처: 코디 카드 좌우 스와이프 (dislike/save)
- 풀 투 리프레시: 피드 상단에서 아래로 당기기
- 롱프레스: 코디 카드 → 퀵 액션 메뉴

### 바텀시트 패턴
- 드래그 핸들 중앙 상단 (40px x 4px)
- 3단계 스냅: peek(30%), half(50%), full(85%)
- 뒤 배경 어둡게 (overlay 0.3 opacity)
- 바깥 탭으로 닫기
- spring 물리: stiffness 300, damping 30

### 스켈레톤 로딩
- 카드 형태 유지한 pulse 애니메이션
- 이미지: 3:4 비율 회색 박스
- 텍스트: 2줄 회색 바
- 스코어: 작은 pill 회색 바

### Safe Area 대응
- 상단: status bar 영역 (env(safe-area-inset-top))
- 하단: home indicator 영역 (env(safe-area-inset-bottom))
- 좌우: 노치 대응 (env(safe-area-inset-left/right))

### 스크롤 동작
- 피드: 무한 스크롤 (intersection observer)
- 스크롤 시 상단 헤더 축소 (sticky, 배경 blur)
- 빠른 스크롤 시 "맨 위로" FAB 표시
- overscroll-behavior: contain (바운스 제어)

### 폰트 최적화
- Nanum Myeongjo: display=swap, subset=korean
- Pretendard: variable font, woff2
- 최소 16px body (iOS 자동 줌 방지)
- -webkit-text-size-adjust: 100%

### 성능 (모바일 네트워크)
- 이미지: WebP, lazy loading, placeholder blur
- 카드 가상화: 화면 밖 카드 DOM 제거
- 번들: code splitting per route
- FCP < 1.5s, LCP < 2.5s 목표
