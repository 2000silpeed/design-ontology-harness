# World Cup Hub - 제품 기획서

## 제품 개요
World Cup Hub는 월드컵 팬이 경기 전후에 가장 자주 확인하는 네 가지 일을 한 화면에서 처리하는 한국어 웹 앱이다.

- 오늘과 이번 주의 경기 일정 확인
- 완료된 경기 결과와 조별 흐름 정리
- 베팅이 아닌 팬 관점의 승부예측 작성
- 경기별 의견, 관전 포인트, 논쟁을 짧게 주고받기

초기 버전은 FIFA World Cup 2026 일정 페이지를 기준 seed로 삼되, 실제 화면은 정적 데모 데이터를 사용한다. 운영 버전에서는 일정/결과 API, 사용자 인증, 댓글 저장소를 교체 가능한 데이터 계층으로 연결한다.

## 제품 약속
팬이 여러 기사, 검색 결과, 커뮤니티 글을 오가지 않아도 "언제 누가 붙는지", "지금 조별 상황이 어떤지", "내 예상과 다른 사람 예상이 어떻게 다른지"를 빠르게 파악한다.

## 핵심 사용자
- **한국 대표팀 팬**: 한국 경기 시간, 상대, 조 순위, 다음 경우의 수를 가장 먼저 확인한다.
- **전 조를 보는 축구 팬**: 빅매치, 이변 가능성, 토너먼트 흐름을 비교해서 본다.
- **스포츠 콘텐츠 운영자**: 경기 전 예측 카드와 경기 후 요약을 빠르게 만들고 싶다.
- **친구 모임/커뮤니티 운영자**: 가벼운 승부예측과 의견 피드를 공유한다.

## 비범위
- 베팅, 도박, 배당률 중심 UI는 만들지 않는다.
- 실시간 중계권 영상 재생은 다루지 않는다.
- 공식 결과처럼 보이는 허위 live state를 만들지 않는다. 정적 데모에는 "데모 데이터" 표시를 명확히 둔다.
- 혐오 표현, 국적 비하, 선수 개인 공격을 조장하는 토론 구조는 피한다.

## MVP 핵심 플로우
1. **일정 보기**
   - 날짜, 조, 팀, 경기 상태로 필터링한다.
   - 사용자의 로컬 시간 기준 킥오프 시간을 노출한다.
   - 즐겨찾기 팀의 경기는 schedule rail과 상단 상태 strip에 고정된다.

2. **경기 상세 확인**
   - 경기 카드에서 팀, 조, 경기장, 킥오프, 현재 상태, 관전 포인트를 본다.
   - 완료 경기에는 스코어, 득점 요약, 조별 영향 요약을 붙인다.
   - 예정 경기에는 주요 matchup, 예측 분포, 의견 수를 보여준다.

3. **승부예측**
   - 사용자는 홈 승/무/원정 승 또는 스코어 예상을 선택한다.
   - 앱은 팬 투표 기반 예측과 편집자 모델 예측을 구분해서 보여준다.
   - 확률 표현은 "팬 예상", "모델 의견"으로 표기하고 betting odds처럼 보이지 않게 한다.

4. **결과 정리**
   - 종료된 경기는 결과 센터에 모인다.
   - 조별 순위, 승점, 득실, 다음 경기 경우의 수를 짧은 문장으로 요약한다.
   - 경기 직후에는 "결과 확정", "기록 검수 중", "요약 업데이트" 상태를 분리한다.

5. **의견 주고받기**
   - 경기별 토론 피드는 짧은 코멘트, 태그, 좋아요, 신고를 제공한다.
   - 댓글 작성 영역은 경기 전에는 예측, 경기 중/후에는 관전평과 결과 반응으로 문맥이 바뀐다.
   - 공격적인 표현을 줄이기 위해 신고, 숨김, 운영자 고정 코멘트 affordance를 둔다.

## 주요 화면
1. **Tournament Dashboard**
   - 오늘 경기 수, 한국 경기 D-day, 완료 경기 수, 가장 의견이 많은 경기, 예측 참여 수를 보여준다.
   - 상단 status strip은 데이터 갱신 시각과 source footnote를 포함한다.

2. **Schedule**
   - 날짜 rail, 조별 chip, 팀 검색, 상태 segmented control을 제공한다.
   - 목록은 경기 번호, 킥오프, 팀, 조, 경기장, 예측 top line, 토론 수를 한 줄에 보여준다.
   - 모바일에서는 날짜 rail과 필터를 상단 sticky 영역으로 압축한다.

3. **Match Detail**
   - 선택한 경기의 주요 정보, 상대 전력 키워드, 예상 라인업 메모, 팬 예측 분포를 보여준다.
   - 예정/진행/완료 상태에 따라 CTA가 "예측하기", "의견 남기기", "결과 보기"로 바뀐다.

4. **Results Center**
   - 완료 경기의 scoreline과 조별 영향 요약을 카드와 테이블로 제공한다.
   - 결과가 없는 초기 상태에서는 "대회 전 데모 데이터"와 "예정 경기"를 명확히 분리한다.

5. **Predictions**
   - 팬 투표, 모델 의견, 내 선택을 비교한다.
   - confidence badge는 근거 수준을 표현한다: 낮음, 보통, 높음.
   - 예측은 경기 시작 전까지 수정 가능하고, 시작 후에는 읽기 전용으로 잠긴다.

6. **Community**
   - 경기별 의견 thread, 추천 의견, 운영자 공지, 신고/숨김 상태를 제공한다.
   - 토론은 경기별로 묶고 국가/선수 비하를 막는 moderation copy를 표시한다.

7. **Standings / Bracket Preview**
   - 조별 순위표와 토너먼트 진출 가능성을 미리 보여준다.
   - 48팀/12조 구조와 best third-place qualification을 설명 없이도 스캔 가능하게 한다.

## 도메인 모델
- **Tournament**: 대회명, 기간, 개최국, 총 경기 수, 데이터 source.
- **Group**: 조 이름, 팀 목록, 순위 테이블, 진출 상태.
- **Team**: 국가명, 코드, 대륙, seed, fan favorite flag.
- **Match**: 경기 번호, 조, 팀 A/B, 날짜, 시간, 경기장, 도시, 상태.
- **MatchResult**: 스코어, 득점자, 카드, 승점 영향, 기록 확정 상태.
- **Prediction**: 경기, 사용자, 선택, 예상 스코어, confidence, 작성 시각.
- **PredictionAggregate**: 팬 투표 분포, 모델 의견, 내 선택 여부.
- **Opinion**: 경기, 작성자, 본문, 태그, 좋아요, 신고 수, moderation state.
- **SourceNote**: 일정/결과 데이터 출처, 갱신 시각, 정적/라이브 여부.

## 주요 컴포넌트
- **app-shell**: 상단 tournament nav, 콘텐츠 영역, 보조 패널.
- **status-strip**: 대회 시작일, 데이터 freshness, source footnote.
- **metric-tile**: 오늘 경기, 완료 경기, 예측 참여, 댓글 수.
- **date-rail**: 날짜별 경기 수와 active state.
- **group-filter-chip**: 조별 필터와 선택 상태.
- **team-search-field**: 팀명 검색과 즐겨찾기 팀 quick filter.
- **schedule-table**: 날짜/시간/팀/조/장소/상태/예측 요약.
- **match-card**: 경기별 카드, kickoff, venue, prediction, discussion count.
- **team-badge**: 국가 코드, 색상, 즐겨찾기 marker.
- **scoreline**: 예정/진행/완료 상태에 맞는 스코어 표시.
- **prediction-panel**: 승/무/패 선택, 스코어 입력, 팬 예측 분포.
- **probability-bar**: 세 결과 확률을 고정 높이 bar로 표시.
- **confidence-badge**: 모델 또는 편집자 의견의 신뢰도.
- **result-summary-card**: 완료 경기 요약과 조별 영향.
- **standings-table**: 팀, 승점, 득실, 순위 변동.
- **opinion-composer**: 짧은 의견 작성, 태그 선택, 제출 상태.
- **discussion-thread**: 의견 목록, 좋아요, 신고, 운영자 고정 글.
- **source-footnote**: 공식 일정 seed와 정적 데모 데이터 구분.
- **empty-state**: 결과가 아직 없을 때 예정 경기 중심으로 안내.

## 정보 구조
- `/` Tournament Dashboard
- `/schedule` 일정
- `/results` 결과
- `/predictions` 승부예측
- `/community` 의견
- `/teams/:teamCode` 팀별 일정
- `/matches/:matchId` 경기 상세

정적 MVP에서는 단일 HTML 안의 tabbed view로 위 구조를 축약한다.

## 디자인 원칙
- 앱의 첫 화면은 마케팅 히어로가 아니라 실제 일정/예측을 조작할 수 있는 운영 화면이어야 한다.
- 정보 밀도는 높게 유지하되, 경기 카드와 표의 행 높이는 모바일에서 손가락 조작이 가능해야 한다.
- 예측 UI는 베팅 사이트처럼 보이면 안 된다. odds, stake, payout 같은 단어를 쓰지 않는다.
- 국가 색상은 보조 신호로만 쓰고, 읽기와 상태 판별은 텍스트/아이콘/형태를 함께 사용한다.
- 카드 안에 카드가 들어가는 구조를 피하고, 반복 항목은 8px 이하 radius의 단정한 surface로 만든다.

## 초기 데모 데이터
정적 목업에는 다음 데이터를 포함한다.
- 2026년 6월 11일 개막일 경기 예시
- 한국이 포함된 Group A 경기 예시
- 조별리그 빅매치 예시
- 완료 경기 예시 2개는 과거 월드컵 형식의 샘플 결과로 표시하되, 2026 공식 결과로 오해되지 않게 "샘플" 상태를 붙인다.

## 성공 기준
- 사용자가 10초 안에 한국의 다음 경기와 킥오프 시간을 찾을 수 있다.
- 일정 목록에서 날짜/조/상태 필터가 즉시 동작한다.
- 경기 카드를 선택하면 예측 패널과 의견 피드가 같은 경기로 갱신된다.
- 정적 데모임을 명확히 보여주면서도 실제 서비스 정보 구조를 검증할 수 있다.
