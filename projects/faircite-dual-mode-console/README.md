# FairCite Dual Mode Console

FairCite v0.2 기획서를 바탕으로 만든 정적 웹서비스 디자인 프로토타입입니다.

## 실행

```bash
cd projects/faircite-dual-mode-console
python3 -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:4173/`을 엽니다.

## 포함 화면

- 컴플라이언스 모드: 자사 리스크 진단, 유사 의결서, 출처 라벨
- 권익보호 모드: 상황 진단 톤 가드, 유사 패턴 문구, 민감정보 배너
- 과징금 산정 구조 분석기: 예측 금지 라벨과 단계형 산정 구조
- 갑질 패턴 카탈로그: P0 카드 갤러리
- 쌍대 케이스 데모: 현대중공업 사건을 두 시점으로 비교
- Evidence Map: chunk, 법제처 조문, 모델 요약 라벨의 우측 근거 패널

## 디자인 방향

첫 화면은 랜딩 페이지가 아니라 심사위원이 바로 이해할 수 있는 콘솔입니다. `의결서 500건`, `31,879 chunks`, `main_score 0.7295`, 출처 라벨 4종을 첫 viewport에 배치해 "근거추적형 서비스" 메시지가 즉시 보이도록 구성했습니다.
