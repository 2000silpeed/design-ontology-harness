# Tinge Mobile Fashion Curation

## Product Concept

Tinge helps Korean mobile shoppers decide how much tension an outfit needs before they browse. The app reads a short occasion pulse, recent closet memory, weather, and the user's preferred style axes. It then calibrates one silhouette and one missing accent, instead of showing an open-ended product feed.

## First Screen Skeleton

Composition: `style compass with closet tape and accent tray`.

The first viewport must include:

- A compact occasion pulse for place, timing, weather, and dress expectation.
- A two-axis style compass that the user can adjust.
- A closet tape showing owned garments as memory tokens.
- A silhouette preview showing the current calibrated direction.
- An accent tray with only a few bounded candidates.
- A decision dock for saving the calibration or sending one accent to candidates.

## Anti-Convergence Rules

- No hero plus card grid.
- No generic marketplace home.
- No Foldline-style look board and contextual shop sheet.
- No dashboard metrics.
- No generic filter chip rail as the primary control.

## Mock UI Requirement

The mock must feel like a mobile calibration instrument for fashion judgment. It should use real garment or textile imagery, compact Korean copy, and controls that show the user is tuning a style direction rather than browsing products.
