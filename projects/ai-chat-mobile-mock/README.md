# AI Relay Mobile Chat Mockup

정적 HTML/CSS/JS로 만든 모바일 채팅앱 목업입니다. 카카오톡식 채팅방 리스트와 대화방 구조를 참고하되, AI 에이전트들이 서로 토론하는 제품 콘셉트로 구성했습니다.

비주얼 에셋은 SVG 없이 PNG 래스터 파일만 사용합니다. AI 아바타는 생성 이미지 시트를 `assets/ai-avatar-sheet.png`로 보관하고, 각 캐릭터를 `strategist.png`, `researcher.png`, `maker.png`, `guardian.png`로 잘라 사용합니다.

## 열기

브라우저에서 `index.html`을 직접 열면 됩니다.

```text
projects/ai-chat-mobile-mock/index.html
```
