# Signal Desk 상세 설계서

## 1. 제품 개요

Signal Desk는 작은 팀과 개인 제작자를 위한 에디토리얼 업무 앱입니다.
콘텐츠 기획부터 발행까지의 워크플로우를 하나의 워크스페이스에서 관리합니다.

## 2. 주요 화면

### 2.1 메인 대시보드

사용자가 로그인하면 대시보드가 표시됩니다.
- 좌측에 사이드바 네비게이션으로 워크스페이스 간 이동
- 상단 탑바에 검색, 알림, 사용자 메뉴
- 중앙에 통계 카드로 이번 주 발행 현황, 팀 활동 요약
- 하단에 최근 활동 피드와 예정된 일정

### 2.2 콘텐츠 에디터

리치텍스트 에디터로 글을 작성합니다.
- 마크다운과 위지윅 모드 전환 가능
- / 슬래시 명령으로 이미지, 코드블록, 테이블 삽입
- 텍스트 선택 시 인라인 포맷 메뉴 표시
- 블록 단위 드래그로 순서 변경

### 2.3 프로젝트 보드

칸반 보드로 콘텐츠 진행 상태를 관리합니다.
- 컬럼: 기획, 작성중, 검토, 발행 완료
- 카드를 드래그하여 상태 변경
- 카드에 담당자 아바타, 마감일, 태그 표시
- 필터: 담당자, 마감일, 태그별 필터링

### 2.4 팀 설정

팀 정보와 멤버를 관리하는 설정 화면입니다.
- 팀 프로필 편집 폼
- 멤버 초대 (이메일 입력)
- 역할 설정 (드롭다운 선택)
- 알림 설정 (체크박스)

### 2.5 검색

글로벌 검색으로 모든 콘텐츠를 찾습니다.
- Cmd+K로 커맨드 팔레트 열기
- 제목, 본문, 태그 통합 검색
- 자동완성으로 빠른 탐색
- 최근 검색 기록 표시

## 3. 알림 시스템

- 새 댓글, 멘션, 마감일 알림
- 토스트로 실시간 알림 표시
- 알림 센터에서 전체 목록 확인
- 이메일 알림 설정 가능

## 4. 파일 관리

- 이미지, PDF 등 파일 업로드
- 드래그앤드롭으로 에디터에 삽입
- 업로드 진행률 표시
- 첨부 파일 미리보기

## 5. 댓글과 리뷰

- 콘텐츠에 인라인 댓글 작성
- @멘션으로 팀원 호출
- 댓글 스레드로 토론
- 리뷰 승인/반려 워크플로우

## 6. 일정 관리

- 캘린더 뷰로 발행 일정 확인
- 날짜 선택으로 마감일 설정
- 주간/월간 보기 전환
