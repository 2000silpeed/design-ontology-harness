업무 선택

EKOS 업무 판단 검토

업무 케이스를 선택하면 EKOS가 필요한 데이터가 충분한지 먼저 확인하고, 지금 해도 되는 일과 하면 안 되는 일을 알려줍니다.

케이스 입력

검토할 케이스 입력

EKOS는 먼저 이 케이스를 판단할 수 있는 데이터가 충분한지 확인합니다. 필수 데이터가 부족하면 판단 결과를 만들지 않습니다.

선택한 업무

납품 지연 / 운송사 확인

납품 지연 건에서 운송사 확인이 충분한지 검토합니다. EKOS는 SAP 변경이나 고객 영향 작업을 직접 승인하지 않습니다.

  • 필요 데이터가 먼저 확인됩니다.
  • 부족한 데이터가 있으면 판단 결과가 생성되지 않습니다.
  • 결과는 “해도 되는 일”과 “하면 안 되는 일”로 표시됩니다.

필요 데이터 검토

판단 불가

필수 데이터가 부족합니다.

판단 결과 생성 안 됨
부족한 정보

운송사 최신 확인 정보와 승인 기준표가 없습니다.

이 두 정보가 없으면 EKOS는 운송사 확인이 최신인지, 승인 준비를 누구에게 넘겨야 하는지 판단할 수 없습니다.
