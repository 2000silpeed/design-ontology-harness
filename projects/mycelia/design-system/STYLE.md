# Mycelia — Style Capsule

> Read this first. Image-first system: tokens/components below were **derived from
> three generated screens** (GPT Image 2), not from any preset or existing project.

**Concept:** Field Guide Naturalism — a vintage letterpress mycology field guide
reinterpreted as a calm, precise modern web interface. Earthy, archival, precise,
tactile, calm.

**Do**
- Warm paper surfaces (`#F4EEE2` canvas, `#FBF7EE` cards) with thin bark hairlines.
- Forest green (`#2F4733`) for primary actions and data; ink (`#2A2622`) for text.
- One accent only: spore amber (`#C8742B`) for the active nav/tab and selected pin.
- Spectral (humanist serif) for wordmark, species Latin names, titles; Source Sans 3
  for UI/body; mono for coordinates, dates, confidence %.
- Edibility is meaningful color: verified green, unverified amber, poisonous brick red.
- Flat paper depth; only the floating map sighting card lifts.

**Don't**
- No neon, no glassmorphism, no default Tailwind blue, no emoji icons.
- No dark techy dashboard, no heavy gradients.
- Don't spread the spore amber accent around — it loses meaning.
- Don't replace the field-guide serif voice with a generic tech sans.

**Accessibility:** ink-on-paper AAA; paper-on-forest AAA; toxic danger chip AA.
Keep edibility states distinguishable by label + icon, not color alone.
