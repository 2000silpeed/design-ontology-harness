# Font Reference — 한글 UI 서체 실무 레퍼런스

## 한글 고딕 (Gothic / Sans-serif)

### Pretendard
- **분류**: 휴머니스트 산세리프
- **제작**: 길형진 (cactus)
- **소스**: GitHub (cactus/pretendard)
- **라이선스**: OFL (무료 상업 사용)
- **웨이트**: 100-900 (9단계), Variable 지원
- **라틴 호환**: Inter 기반 — x-height, weight 일치
- **글자폭**: 중간 (영문 대비 약 1.1배)
- **자소 균형**: 우수 — 초성/중성/종성 공간 배분이 균등하고 시각 무게중심이 안정적
- **소형 가독성**: 13px까지 본문 가독성 유지, 11px에서도 UI 라벨 판독 가능
- **행간 권장**: 본문 1.6-1.7, UI 라벨 1.4-1.5
- **자간 특성**: 기본 자간이 자연스러워 letter-spacing 조정 불필요
- **렌더링 특성**: macOS/Windows 모두 안정적. 힌팅 최적화로 Windows에서도 깨끗
- **사용 서비스**: 토스 (toss.im), 당근마켓, 리디 (RIDI), Velog, 채널톡, 토스페이먼츠
- **적합한 용도**: UI 전반, 대시보드, 모바일 앱, SaaS, 장문 본문
- **부적합한 용도**: 없음 (범용)
- **페어링**: Inter(라틴), Noto Serif KR(세리프 헤딩), JetBrains Mono(코드)
- **선택 이유**: 한글 UI 서체의 사실상 표준. 자간/행간 기본값이 뛰어나서 추가 조정 없이 바로 사용 가능. 9단계 weight로 위계 표현 자유도 높음. Variable 지원으로 파일 크기 최적화.

### Wanted Sans
- **분류**: 기하학적 산세리프
- **제작**: 원티드랩 (wanteddev)
- **소스**: GitHub (wanteddev/wanted-sans)
- **라이선스**: OFL
- **웨이트**: 400-800 (5단계), Variable 지원
- **라틴 호환**: Plus Jakarta Sans와 weight/personality 유사
- **글자폭**: 중간-좁음 (Pretendard보다 약간 좁음)
- **자소 균형**: 우수 — 현대적 비율, 초성이 약간 작고 중성이 넓어 경쾌한 인상
- **소형 가독성**: 13px까지 가독성 유지, 12px 이하에서는 Pretendard보다 떨어짐
- **행간 권장**: 본문 1.5-1.6, 헤딩 1.2-1.3
- **자간 특성**: 기본 자간이 좋으나 Pretendard보다 약간 타이트
- **렌더링 특성**: macOS 우수, Windows에서 Regular weight가 약간 가늘게 보일 수 있음
- **사용 서비스**: 원티드 (wanted.co.kr), 그린랩스
- **적합한 용도**: SaaS, 모바일 앱, 현대적 브랜딩, 볼드 헤딩
- **부적합한 용도**: 장문 본문 (Pretendard보다 line-height 여유 적음), 공공/기관 (너무 현대적)
- **페어링**: Plus Jakarta Sans(라틴), Pretendard(본문 폴백)
- **선택 이유**: Pretendard보다 현대적이고 자신감 있는 인상. Bold weight에서 헤드라인 임팩트가 강함. 스타트업/테크 브랜딩에 적합.

### Noto Sans KR
- **분류**: 휴머니스트 산세리프
- **제작**: Google / Adobe (산돌 협력)
- **소스**: Google Fonts
- **라이선스**: OFL
- **웨이트**: 100-900 (9단계), Variable 미지원 (정적 woff2)
- **라틴 호환**: Noto Sans (같은 Noto 패밀리)
- **글자폭**: 넓음 (영문 대비 약 1.2배 — 한글 서체 중 가장 넓은 축)
- **자소 균형**: 양호 — 고딕 기반 정돈된 형태, 다만 자소 크기가 커서 공간 소모 큼
- **소형 가독성**: 12px까지 가독성 유지 (글자가 커서 작은 크기에서도 판독 가능)
- **행간 권장**: 본문 1.6-1.8 (글자폭이 넓어 행간도 넉넉히)
- **자간 특성**: 기본 자간이 넓은 편, letter-spacing: -0.01em 정도 조정하면 나아짐
- **렌더링 특성**: 모든 OS에서 안정적. 파일 크기가 큼 (subset 권장)
- **사용 서비스**: Google 한국 서비스, 정부24, 공공데이터포털, 네이버 일부
- **적합한 용도**: 다국어 서비스, 공공/기관, 문서 중심, 장문 본문
- **부적합한 용도**: 좁은 UI 공간 (글자폭이 넓어 카드/뱃지에서 잘림), 모바일 밀집 UI
- **페어링**: Noto Sans(라틴), Noto Serif KR(세리프 헤딩)
- **선택 이유**: 다국어 지원이 필요하거나 공공 서비스의 기본 선택. 글자폭이 넓어 여유 있는 레이아웃에서 가장 가독성이 좋음. 단, 파일 크기와 글자폭 때문에 모바일에서는 Pretendard가 나음.

### SUIT
- **분류**: 휴머니스트 산세리프 (소프트)
- **제작**: 순 타입페이스 (sun-typeface)
- **소스**: GitHub (sun-typeface/SUIT)
- **라이선스**: OFL
- **웨이트**: 100-900 (9단계), Variable 지원
- **라틴 호환**: Inter 계열 (Pretendard와 유사)
- **글자폭**: 중간 (Pretendard와 유사)
- **자소 균형**: 양호 — Pretendard 계열이지만 꼭짓점이 약간 둥글어 부드러운 인상
- **소형 가독성**: 13px까지 가독성 유지
- **행간 권장**: 본문 1.6-1.7
- **자간 특성**: Pretendard와 유사, 기본값 양호
- **렌더링 특성**: macOS/Windows 모두 안정적
- **사용 서비스**: 인프런, 소규모 스타트업 다수
- **적합한 용도**: 소비자 앱, 모바일, 친근한 톤의 서비스, 교육, 라이프스타일
- **부적합한 용도**: 기관/금융 (너무 캐주얼할 수 있음), 데이터 대시보드 (Pretendard가 더 적합)
- **페어링**: Outfit(라틴), Quicksand(라틴 라운드)
- **선택 이유**: Pretendard보다 부드럽고 친근한 인상. 교육, 커뮤니티, 라이프스타일 서비스에서 Pretendard의 진지함을 피하고 싶을 때 선택.

### Spoqa Han Sans Neo
- **분류**: 기하학적 산세리프
- **제작**: 스포카 (Spoqa)
- **소스**: GitHub (spoqa/spoqa-han-sans)
- **라이선스**: OFL
- **웨이트**: 100-700 (4단계), Variable 미지원
- **라틴 호환**: Source Sans Pro 기반
- **글자폭**: 중간-좁음
- **자소 균형**: 양호 — 기하학적이고 깔끔, 직선적 인상
- **소형 가독성**: 13px까지 가독성 유지
- **행간 권장**: 본문 1.5-1.6
- **자간 특성**: 기본 자간이 약간 넓음, 밀집 UI에서는 letter-spacing: -0.02em 권장
- **렌더링 특성**: macOS 우수, Windows에서 Thin weight 힌팅이 약함
- **사용 서비스**: 스포카 (도도포인트), 요기요, 여기어때
- **적합한 용도**: SaaS, 데이터 대시보드, 깔끔한 UI
- **부적합한 용도**: 장문 본문 (line-height 여유 부족), 감성적 브랜딩
- **페어링**: Source Sans 3(라틴), Space Grotesk(라틴 데이터)
- **선택 이유**: Pretendard 이전 시대의 한글 UI 표준이었음. 여전히 깔끔하지만 weight 범위와 Variable 미지원이 아쉬움. 신규 프로젝트에서는 Pretendard를 추천.

### IBM Plex Sans KR
- **분류**: 휴머니스트 산세리프
- **제작**: IBM / 산돌
- **소스**: Google Fonts
- **라이선스**: OFL
- **웨이트**: 100-700 (7단계), Variable 미지원
- **라틴 호환**: IBM Plex Sans (같은 패밀리)
- **글자폭**: 중간
- **자소 균형**: 우수 — IBM 디자인 철학에 맞게 정밀하게 설계
- **소형 가독성**: 12px까지 가독성 유지 (힌팅 우수)
- **행간 권장**: 본문 1.5-1.6
- **자간 특성**: 기본 자간 양호, 약간 타이트한 편
- **렌더링 특성**: 모든 OS에서 매우 안정적 (IBM이 힌팅에 투자)
- **사용 서비스**: IBM Korea, Carbon Design System 한국 프로젝트
- **적합한 용도**: 기업용 소프트웨어, 금융, 데이터 분석, B2B SaaS
- **부적합한 용도**: 소비자 앱 (너무 기관적), 감성적 콘텐츠
- **페어링**: IBM Plex Sans(라틴), IBM Plex Mono(코드) — 같은 패밀리로 통일 가능
- **선택 이유**: Sans/Serif/Mono 세 패밀리가 같은 디자인 언어로 통일된 유일한 한글 서체. 기업용 제품에서 일관성이 중요할 때 최적.

## 한글 명조 (Myeongjo / Serif)

### Noto Serif KR
- **분류**: 현대 명조
- **제작**: Google / Adobe (산돌 협력)
- **소스**: Google Fonts
- **라이선스**: OFL
- **웨이트**: 200-900 (7단계), Variable 미지원
- **라틴 호환**: Noto Serif (같은 패밀리), Playfair Display(성격 유사)
- **글자폭**: 넓음 (고딕보다 더 넓음)
- **자소 균형**: 우수 — 전통 명조의 획 대비를 현대적으로 재해석
- **소형 가독성**: 14px 이상 권장 (세리프 특성상 작은 크기에서 획이 뭉침)
- **행간 권장**: 본문 1.7-1.9, 헤딩 1.2-1.4
- **자간 특성**: 기본 자간이 넓은 편, 헤딩에서는 letter-spacing: -0.02em 권장
- **렌더링 특성**: macOS 우수, Windows에서 가는 획이 날카롭게 보일 수 있음
- **사용 서비스**: 브런치 (brunch.co.kr), 퍼블리 (publy.co), 독립 출판 사이트
- **적합한 용도**: 에디토리얼 헤딩, 콘텐츠 플랫폼, 매거진, 장문 읽기, 럭셔리 브랜딩
- **부적합한 용도**: UI 라벨 (작은 크기 가독성 저하), 모바일 본문 (화면이 좁으면 답답), 데이터 대시보드
- **페어링**: Pretendard(고딕 본문), Lora(라틴 세리프), Playfair Display(라틴 세리프 헤딩)
- **선택 이유**: 한글 세리프 웹폰트 중 사실상 유일한 고품질 선택지. 헤딩에서 격조 있는 인상. 에디토리얼 제품에서 "고딕만 쓰는 밋밋함"을 깨뜨릴 수 있는 유일한 옵션.

### KoPubWorldBatang
- **분류**: 전통 바탕체
- **제작**: 한국출판인회의
- **소스**: 한국출판인회의 배포
- **라이선스**: 무료 (조건부)
- **웨이트**: 300-700 (3단계)
- **라틴 호환**: Libre Baskerville (성격 유사)
- **글자폭**: 넓음
- **자소 균형**: 전통적 — 인쇄용 바탕체에 가까운 비율
- **소형 가독성**: 14px 이상 권장
- **행간 권장**: 본문 1.8-2.0 (전통 조판 기준)
- **자간 특성**: 인쇄 기준 자간, 웹에서는 약간 넓게 느껴짐
- **렌더링 특성**: 인쇄 최적화, 웹 렌더링은 Noto Serif KR보다 불안정
- **사용 서비스**: 출판사 웹사이트, 정부 문서
- **적합한 용도**: 출판물, 공공 문서, 법률/계약서, 전통적 인상이 필요한 서비스
- **부적합한 용도**: 모던 UI (너무 전통적), 모바일 (글자폭+웹 렌더링), SaaS
- **페어링**: Libre Baskerville(라틴), Noto Sans KR(고딕 본문)
- **선택 이유**: 전통적 권위가 필요한 맥락에서만 사용. 웹에서는 거의 모든 경우 Noto Serif KR이 더 나은 선택.

### 제품 유형별 추천

| 제품 유형 | 1순위 | 2순위 | 이유 |
|----------|-------|-------|------|
| SaaS / 대시보드 | Pretendard | Wanted Sans | 범용성, weight 범위, 자간 안정성 |
| 모바일 앱 | Pretendard | SUIT | 소형 가독성, 파일 크기 |
| 에디토리얼 / 콘텐츠 | Noto Serif KR(헤딩) + Pretendard(본문) | Wanted Sans(헤딩) + Pretendard(본문) | 세리프+고딕 대비로 위계 |
| 기업용 / B2B | IBM Plex Sans KR | Pretendard | Sans/Serif/Mono 패밀리 통일 |
| 공공 / 기관 | Noto Sans KR | Pretendard | 다국어, 접근성, 공식적 인상 |
| 소비자 앱 (친근) | SUIT | Pretendard | 둥근 인상, 친근함 |
| 데이터 집약 | Pretendard + JetBrains Mono | Spoqa Han Sans Neo | 숫자 가독성, tabular figures |
| 패션 / 럭셔리 | Noto Serif KR | — | 격조, 에디토리얼 위계 |
